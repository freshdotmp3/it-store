[ ผู้จัดทำ ]
นาย ศรายุทธ โพธิ์ทรง (ปวช. 2/1) 
แผนกวิชาเทคโนโลยีสารสนเทศ


[ สาเหตุที่ทำโปรเจกต์นี้ ]
ที่แผนก IT ของเรามีร้านค้าเล็กๆ ขายขนม ของกินเล่น แล้วก็เครื่องดื่ม ซึ่งปกติพวกเราจะซื้อเอง จ่ายตังเอง แล้วก็หยิบเงินทอนเองจากกล่องอยู่แล้ว 

แต่ปัญหาหลักๆ ที่เจอคือ:
1. ปัญหาจากตัวผมเองล้วนๆ เวลาผมซื้อของ ผมมักจะจ่ายเป็น "แบง" (เช่น พวกแบง 50 ไม่ก็ 100) แล้วผมเป็นคนที่ขี้เกียจยืนคิดเลขในหัวมากว่าต้องทอนเท่าไหร่ เว็บนี้ผมเลยจัดระบบคิดเงินทอนให้อัตโนมัติซะเลย ใส่เลขปุ๊บ บอกปั๊บว่าต้องหยิบเงินทอนกี่บาท สบายสมองขึ้นเยอะสำหรับคนขี้เกียจ
2. เวลาคนจะ "โอนจ่าย" ต้องคอยหาปากกากับเศษกระดาษมานั่งเขียนว่า ชื่อใคร โอนกี่บาท โอนตอนกี่โมง ซึ่งมันยุ่งยาก เสียเวลามาก ลายมือก็อ่านไม่ออก
3. คนซื้อบางทีก็คิดเลขทอนเงินผิดๆ ถูกๆ หยิบเงินทอนเกินบ้างขาดบ้าง
4. สงสารเพื่อนผม(ภูผา) ที่ต้องดูแลร้านนี้ ทุกเย็นต้องมานั่งนับเหรียญนับแบงซ้ำแล้วซ้ำเล่าเพื่อเช็คยอดว่าเงินตรงไหม เงินหายหรือเปล่า

ผมเห็นแล้วเหนื่อยแทน (และขี้เกียจคิดเงินทอนเองด้วย) เลยเขียนเว็บนี้ขึ้นมาใช้ในแผนกสะเลย


[ ปัญหาที่เจอ (ก่อนทำระบบ) ]
- คนซื้อ (รวมถึงตัวผมด้วย) ขี้เกียจคิดเลขในหัวเวลาจ่ายแบง ว่าต้องหยิบเงินทอนออกจากกล่องเท่าไหร่
- การจดใส่กระดาษเวลาโอนเงินมันวุ่นวาย ตกหล่นง่าย ลายมืออ่านยาก
- คนดูแลร้านเช็คยอดเงินยาก ต้องเสียเวลานับเงินสดวนไปวนมาเทียบกับสลิปโอน


[ วัตถุประสงค์ (ทำมาเพื่ออะไร) ]
- ช่วยคิดเงินทอนให้อัตโนมัติ (kitmoneyChikChing) สบายสมอง ไม่ต้องยืนคิดเลขเองให้ปวดหัว และไม่หยิบเงินทอนพลาด
- เลิกใช้กระดาษ ให้คนโอนเงินมากรอกข้อมูลในเว็บแทน มี QR Code อันใหญ่ๆ ให้สแกนได้ทันที
- รวมยอดเงินให้เสร็จสรรพในหน้าเดียว ทั้งเงินสด เงินทอน เงินโอน เพื่อนผมที่ตรวจร้านจะได้ดูยอดรวมได้ทันที ไม่ต้องมานั่งนับเงินซ้ำๆ จนมึน


[ สิ่งที่ระบบทำได้ ]
- ระบบคิดเงินทอนออ "โต้": จ่ายแบงอะไรมา แค่ใส่เลข เงินทอนจะคำนวณและเด้งขึ้นมาเป็นแถบสีเหลืองชัดๆ ทันที
- สลับแท็บง่ายๆ: มีให้เลือกว่าจะ "จ่ายเงินสด" หรือ "สแกนจ่าย"
- มี QR Code รับเงินอันใหญ่ๆ: ยกมือถือขึ้นมาสแกนได้สะดวก ชัดเจน
- สรุปยอดเงิน 4 ช่อง: ดูได้ทันทีว่า เงินสดเข้ากล่องกี่บาท, ทอนไปเท่าไหร่, เงินโอนกี่บาท, และยอดรวมทั้งหมดเท่าไหร่
- ตารางบันทึกข้อมูล: เรียงจาก "รายการใหม่ล่าสุดขึ้นก่อน" เสมอ ตรวจสอบง่าย
- ปุ่มล้างข้อมูล: เอาไว้กดรีเซ็ตเคลียร์ตารางเวลาสรุปรอบใหม่


[ ข้อมูลทางเทคนิค ]
- หน้าเว็บ: HTML, Bootstrap 5, Bootstrap Icons, JavaScript
- หลังบ้าน: PHP (เชื่อมต่อกับ MySQL บน XAMPP)
- ฐานข้อมูล: it_store_db (ตาราง transactions)
